# 103-15: Lloyd-Max 量化器的可视化

`103-15.py` 用动画展示了 **Lloyd-Max 算法**（一维标量量化的经典迭代算法）如何从均匀初始量化水平出发，逐步收敛到对给定分布最优的量化器。

最终效果：四个子图同步演化，可以一眼看到「决策边界在变、样本归属在变、阶梯映射在变、MSE 在下降」。

---

## 1. 算法背景

### 什么是标量量化

把连续值 `x ∈ ℝ` 映射成有限个离散值 `x̂ ∈ {ℓ₁, ℓ₂, ..., ℓK}`：

```text
x ──► Q(x) ──► x̂
```

最朴素的做法是均匀量化：把 `[xmin, xmax]` 等分成 K 段，每段取中点。但对 **非均匀分布** 的信号，均匀量化不是最优的——高概率区域应当切得更细、低概率区域切得更粗。

### Lloyd-Max 算法

交替做两件事直到收敛：

1. **给定水平** `ℓk`，找最优决策边界 `bk = (ℓk + ℓk+1) / 2`
2. **给定边界** `bk`，找最优水平 = 该区间内样本的 **条件均值** `ℓk = E[x | x ∈ (bk-1, bk)]`

这就是 K-Means 在一维的特例（用 L2 距离 / MSE 准则）。

## 3. 四子图详解

### 3.1 左上：Histogram + Decision Boundaries

把分布的真实形状、决策边界、量化水平画在同一张图上。

- **浅灰直方图**：经验密度估计
- **蓝色曲线**（新增）：真实 PDF 参考线
  - uniform: `1 / (xmax - xmin)`
  - gaussian: `1/√(2π) · exp(-x²/2)`
- **绿色虚线**：决策边界 `bk`
- **红色圆点**（在 y=0 处）：量化水平 `ℓk`

随着迭代，可以看到红色点逐渐向高密度区域靠拢、绿色虚线在高密度区变密。

### 3.2 右上：Sample Assignment

每个样本按所属量化区间上色，画在轻微抖动的 y 坐标上（`-0.05 ~ 0.05`）。

```text
○ ○ ○ ○        ← k=0 (蓝)
   ● ● ● ● ●   ← k=1 (橙)
▲ ▲ ▲ ▲ ▲ ▲ ▲  ← k=2 (绿)
```

抖动让点不会全部挤在 y=0，看起来像不同的水平条带，方便看出「每个簇里有多少样本」。

### 3.3 左下：Quantization Mapping

这是 Lloyd-Max 算法最经典的展示方式——把量化器当成一个函数画出来。

- **灰色虚线**：`y = x`（无量化时的理想恒等映射）
- **蓝色阶梯**：当前量化器 `y = Q(x)`
  - 在区间 `(bk-1, bk]` 上恒等于 `ℓk`
- **红色点**：量化水平 `(ℓk, ℓk)`

如果完全没有量化，蓝色阶梯就和灰色虚线重合。两者偏离越大，量化损失越大。

随着迭代，蓝色阶梯会逐渐稳定下来，**高密度区间的台阶更窄**（更精细）、低密度区间的台阶更宽（更粗糙）。

### 3.4 右下：MSE Convergence

- **银灰线**：从第 0 轮到收敛的完整 MSE 曲线
- **红色折线 + 圆点**：当前帧之前的历史轨迹
- **蓝色大圆点**：当前帧的 MSE
- **左上文本框**（新增）：

  ```text
  Iteration : 5
  MSE : 0.0234
  ```

典型的 Lloyd-Max 收敛曲线应该是**单调递减**且快速稳定。

## 5. 关键代码片段

### 5.1 训练核心

```python
# 1. 给定 levels，求 boundaries（取相邻中点）
boundaries[1:-1] = (levels[:-1] + levels[1:]) / 2

# 2. 给定 boundaries，把样本分到 K 个区间
labels = np.digitize(x, boundaries[1:-1])

# 3. 更新每个 level = 该区间样本的条件均值
for k in range(self.n_levels):
    if np.any(labels == k):
        new_levels[k] = np.mean(x[labels == k])
```

### 5.2 阶梯函数构造

```python
xx = np.linspace(xmin, xmax, 1000)
yy = np.zeros_like(xx)
for k in range(self.n_levels):
    left, right = boundaries[k], boundaries[k+1]
    yy[(xx >= left) & (xx < right)] = levels[k]

ax.step(xx, yy, where="post", ...)
```

`where="post"` 让阶梯在边界右侧跳变——和数字化量化器的标准画法一致。

## 6. 教学要点

1. **算法单调收敛**：MSE 严格递减（K-Means / Lloyd 的标准结论）
2. **最优性**：当分布已知时，Lloyd-Max 给出的量化器是 MSE 最优的
3. **不均匀切分**：高概率区间的边界更密、台阶更窄
4. **可与 K-Means 对照**：完全一样的两步迭代，只是限定在一维
5. **过载 / 削波**：当前实现假设数据落在 `[xmin, xmax]` 内；极端值会被分到首尾两个 infinite 区间
